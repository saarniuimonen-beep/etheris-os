# Security Policy

## Supported versions

Alpha builds receive best-effort fixes only. There is no long-term support promise yet.

## Reporting a vulnerability

Do **not** open a public issue for sensitive reports until a private contact is published.

When GitHub Security Advisories are enabled, use that. Otherwise contact the owner through the private channel they provide.

## Baseline

See `docs/SECURITY.md` for shipped defaults (firewall, no telemetry, SSH off by default) and explicit limitations.
